# Seus direitos (LGPD)

A Lei Geral de Proteção de Dados (Lei nº 13.709/2018) garante a você, titular dos dados, os direitos abaixo (art. 18). No MyBarber, a maioria deles pode ser exercida direto no App.

| Direito | Como exercer no MyBarber |
| --- | --- |
| Confirmação e acesso aos dados | **Perfil → Privacidade → Baixar meus dados** gera um arquivo com tudo o que guardamos sobre você |
| Correção de dados incompletos ou desatualizados | **Perfil → Editar perfil** |
| Portabilidade | O arquivo de "Baixar meus dados" está em formato aberto (JSON) |
| Eliminação | **Perfil → Privacidade → Excluir minha conta**: seus dados pessoais são anonimizados e suas reservas futuras canceladas |
| Revogação do consentimento | Localização: desative nas configurações do celular. Notificações: desative no App ou no aparelho |
| Informação sobre compartilhamento | Compartilhamos dados apenas com a barbearia em que você agenda e com os fornecedores que hospedam o sistema (veja a Política de Privacidade) |
| Oposição e revisão | Envie sua solicitação ao Encarregado (abaixo) |
